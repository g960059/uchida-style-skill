## v4 の検証と v4.1

- heldout H1〜H6 で v3 と v4 を同じ束に混ぜて採点した。Opus審査の総合点は Opus 6.7/6.0 → 6.3/5.7、GPT 5.3/4.3 → 5.0/4.7。差はどれも ±0.4 以内で、**点数上は互角**だった。

### 残っている限界
- **同じ課題を書いた文章どうしが、同じ洞察に収束する**（モデルが違っても）。一篇ずつ書く実際の使い方では問題になりにくいが、「量産品」の印象の主な原因として審査員が最後まで指摘し続けた。
- **温度の低さ**（「品がよすぎる」「行儀がよい」）は r1 から最後まで残った。規則を足すほど書き手は慎重になる、という構造的な問題で、規則の追加では解けなかった。
- **審査員間の甘さの差**：Gemini は Opus が書いた篇に Opus 審査より 1〜3 点高い点を付ける。ただし、条件間の順位（skillなし < skillあり）は両審査員で一致した。

## v4.2 → v5（長文への対応）

5000〜8000字の3課題（L1 失敗が怖い／L2 地方で暮らす・講演録／L3 「わかりやすさ」・新書の一章）で、skillなしと v4.2 を比べた（`reader/long0_*`、長文版の評価基準 `reader_rubric_long.md`：中だるみ・全体の見通し・反復・読む手が鈍った地点を追加）。

- Opus：skillなし 5.0 → v4.2 7.7（Opus審査）、5.0 → 9.0（Gemini審査）。長文でも効いた。
- **GPT：6.7 → 6.0（Opus審査）、7.3 → 7.3（Gemini審査）。短文の skill を長文に当てはめると、GPT では効かないか逆効果だった。** 全体の見通し 6.3→4.7、中だるみのなさ 5.7→4.7（Opus審査）。

審査文から見えた長文の失敗：
- 全体の60〜85%で「結論の言い換え」の区間に入り、読み手が飛ばし読みを始める（「核は一つ」を水増しした形）。
- 張りが続いた長文は、中盤で書き手が自分の立てた説明を疑い直していた（二度目のひねり）。
- 概念を一つずつ同じ入り方で検討していく評論調の区間、具体像を結ばない鍵語、途中で評論文体に切り替わる講演録。
- skill の「見出しを使わない」が新書の章でも効いてしまい、見通しが悪くなった。
