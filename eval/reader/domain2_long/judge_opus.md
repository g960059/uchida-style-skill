# 読み物としての評価（長文版・domain2_long）

8本すべてを最後まで通読してから採点した。課題P5はどの本も「最後尾の札」「割り込み」「並ばない自分」という似た材料を使っている。差が出たのは、材料を使ったあとに何を見つけたか、そしてどう着地したかだった。

- いちばん良かった箇所：「私は生まれてはじめて、見ず知らずの人の食欲を本気で憎んだ」。そして結びの「悪いことをしたとは思わなかった。思わずに済むように、あの順番はできている。」。来た順は中身がないからこそ誰も値踏みしない、という発見が、最後の一行で冷たく、しかも正確に回収される。
- いちばん引っかかった箇所：「あれはほとんど、駕籠の中の殿様である」。大名行列で列の中ほどを持ち上げるくだりは見立てとして凝りすぎていて、書き手が自分の比喩に酔っているように見える。「一つだけ大きな違いがある」と言っておいて説明を後回しにする引っ張り方も、引きとして効く前にもどかしさが来る。
- 中だるみ：中盤の宅配便の再配達から大名行列までの段落（全体の35〜55%あたり）。パン屋の場面が始まるまで観念的な見立てが続き、体温が下がる。パン屋に入ってからは最後まで緩まない。

### 課題P5の順位
1. S04：計算機の行列、待機児童、予約という特権と、発見が三段に重なる。そのうえ額縁の結末で笑わせて締める。いちばん「載せたい」と思えた。
2. S01：「来た順は中身がないから誰も値踏みしない」という洞察がいちばん深く、結びが残酷で美しい。大名行列の見立てに凝りすぎたのが惜しい。
3. S03：場面の描写と笑いでは群を抜くが、論を立てては崩すことを繰り返しすぎて、全体の見通しが濁った。
4. S02：宝くじで仮説を検証するところは誠実で良い。ただ着地が社会批評の定番の型に寄り、結末の効きも弱い。

## 全体の所見
1. **仮説を自分で壊す瞬間の質**：上位作（S04、S01、S05、S08）は、書き手自身が「得をしている側」「逃げていた側」だったと気づくところで加速する。予約という特権、パン屋で他人の食欲を憎む自分、逃げ足の速い新人、夕方を守る赤ペン。気づきが自分を刺しているときに読み手は膝を打つ。社会一般の批判に流れると（S02の後半、S06の病院論）一気に冷める。
2. **答えより、答えに至る具体**：P6はどの本も「距離を決めるのは患者側」という似た結論に向かう。勝負を分けたのは、リモコン、テレビカード、布団から出てくる腕、濡れたシーツといった、ひとつの物でその結論を見せられたかどうかだった。物が強い本ほど記憶に残る。
3. **寄り道の重さ**：大名行列（S01）、文楽（S07）、「看」の字源（S06）のような教養の挿話は、本筋に戻ったときに新しい見え方を一つ足せなければ失速点になる。S04の計算機キューは寄り道でありながら本論の発見そのものになっていて、ここがはっきり分かれ目だった。
4. **論の数**：S03とS08は面白い論点を詰め込みすぎて、全体の見通しが濁った。長文で張りを保つのは論の数ではなく、一本の筋がどう転回するかだ。
5. **結末の作り方**：額縁で閉じる（S04）、冷たい一行（S01）、物で閉じる（S05）、と結末が強い本は読後の評価全体を引き上げる。S02やS06のように、静かに終えようとして余韻が「よくある型」に落ちると、それまでの良さが目減りする。
