# 補助線（脱線）の分析基準

以下の匿名の日本語の文章それぞれについて、**補助線**を特定して分類してください。補助線とは、題材とは一見関係のなさそうな話へ脱線し、そこから本題を照らし直す箇所のことです（題材そのものの具体例や、題材の当事者の場面は補助線に含めません）。文体の良し悪しや、誰かの文体に似ているかは評価しません。

## 各サンプルについて答えること

1. 補助線の数（0〜3）
2. 補助線ごとに：
   - 内容の要約（20字以内）
   - 領域（次から一つ）：思想・哲学／武道・稽古／古典・伝統芸能／映画・文学・漫画などの作品／歴史／昔の職業・商習慣／現代の職業の現場／生物・医療／工学・技術／物流・経済の仕組み／遊び・ゲーム・スポーツ／言葉・語源・翻訳／自然・天気・地学／家事・料理・日常の暮らし／その他
   - 具体性（1〜5）：1＝領域の名前で止まった比喩（「人生は山登り」）、3＝ある程度具体的、5＝固有の細部まで降りていて、その分野を知る人がうなずく
   - 反転（あり／なし）：補助線の話の中で予想外の転回が起き、それが本題を読み替える鍵になっているか
   - 事実の危うさ（なし／あり）：誤り、または確かめようのない数値・固有名・研究結果を断定していないか。ありなら該当箇所を短く引用
3. 書き手の得意領域（課題文の「書き手について」）が指定されている課題では：その領域を補助線または核の近くで使っているか（使っている／触れる程度／使っていない）

## 出力形式

サンプルごとに短く書いたあと、最後に次の形式のJSONコードブロックを1つ置いてください（キー名は固定）。

```json
{"S01": {"n": 1, "lines": [{"summary": "", "domain": "", "concreteness": 0, "reversal": true, "fact_risk": false}], "persona_use": "使っている"}}
```

persona_use は、書き手の得意領域が指定されていない課題では null にしてください。
