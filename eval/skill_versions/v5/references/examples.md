# 文例

以下はすべてこのskillのために書いたオリジナルの模作で、実在の書き手の文章ではない。三つの例は、開示の型・入口・着地をわざと違うものにしてある。語句をそのまま流用せず、**運び方**（何をいつ明かすか、補助線をどう戻すか、どこで力を抜くか）を参考にすること。言い回しを写すと、複数の文章で同じ句が並んでしまう。

---

## 例1：エッセイ（だ・である体／遅延開示／入口：人の一言／常識：途中で敵役として／補助線：『七人の侍』／着地：円環）

「町内会の役員を引き受けてしまった」

ゴミ当番の札を渡しに来た隣のご主人が、玄関先でそうこぼした。引き受けた、ではなく、引き受けて「しまった」。日本語はよくできている。

町内会の加入率が下がっている、という記事をよく見かける。会費が無駄だ、行事が面倒だ、役員の負担が重い。どれも実際に聞く話で、私も総会に一度出て、議事が二時間かかったときにはさすがに閉口した。

でも、「役に立たないからやめる」という理屈には、どこか勘定の合わないところがある。

黒澤明の『七人の侍』で、野武士に狙われた村の百姓たちは侍を雇う。払えるのは米の飯だけである。腕の立つ侍が、そんな条件で命を張る理由はどこにもない。ところが侍たちは集まってくる。勘兵衛という年長の侍が最初に引き受けてしまい、彼の人柄に惹かれた者が一人、また一人と加わっていく。誰も損得の計算はしていない。計算をしたら、誰も来ないからである。そして映画の最後に、生き残った勘兵衛は、田植えをする百姓たちを眺めながら、勝ったのは自分たちではない、と呟く。守った人たちは、守ってもらったことにたいして恩に着るでもなく、もう次の季節の仕事をしている。守る者と守られる者のあいだには、そういう非対称がある。そして、非対称なままで共同体はちゃんと回っている。

町内会もたぶん、そういうふうにできている。

ゴミ捨て場の掃除も、防犯灯の電球の交換も、夏祭りのテントの組み立ても、誰かがやらないと誰も困らないうちに少しずつ町が傷んでいく、という種類の仕事である。だから「得をする人」がはっきりしない。はっきりしないから、会費の使い道として説明しにくい。説明しにくいから、合理的な人ほど抜けていく。けれども、こういう仕事は、損得を計算しない人が「しょうがないなあ」と引き受けてしまうことでしか回らない。集団の力というのは、構成員の能力を足し合わせたものではなくて、誰の担当でもない仕事を誰かが黙って拾うかどうかで決まる。それ以外に、集団が集団である理由はないのである。

加入率の低下を嘆く記事は、たいてい「町内会の魅力を高めよう」と結ぶ。魅力で人を集めようとすると、町内会は会員にサービスを提供する団体になる。会員はお客さんになって、サービスの質に不満を言い始める（総会の二時間は、たぶんそうやって長くなった）。

隣のご主人は、来年の春まで役員を務める。札を受け取りながら、「お疲れさまです」と言いそうになって、まだ何も始まっていないことに気がついた。引き受けて「しまった」人には、とりあえず、それくらいしか言えない。

## 例2：書き換え（だ・である体／暴論の先出しに近い／原文の前提語「メリット」を疑う／エンジンE／着地：力を抜いて切る）

### 元の文章（AI的）

近年、若者の読書離れが深刻な問題となっています。スマートフォンの普及により、短い動画やSNSに時間を費やす傾向が強まっています。読書には語彙力や想像力を養うなど多くのメリットがあるため、学校や家庭が連携して読書の機会を増やすことが重要です。

### 書き換え後

若い人が本を読まなくなった、という話をよく聞く。スマホが時間を奪っている、というのが大方の見立てである。それはたぶんその通りなのだろう。

私が引っかかるのは、そのあとに必ず続く「読書にはこんなメリットがある」という勧め方のほうだ。

語彙が増える。想像力が育つ。嘘ではない。けれども、効能書きを読んでから飲む薬がおいしかったためしはない。効くかどうかばかりが気になって、味がしないからである。読書の効能を数え上げるたびに、本はスマホと同じ棚に並べられて、どちらが「お得」かを比べられることになる。比べられたら、本はまず勝てない。

子どもの頃の私が夢中で本を読んだのは、役に立つからではなかった。父が書斎で背中を丸めて読んでいるものを、こっそり覗いてみたかっただけである。何が書いてあるのかはわからなかった。わからないのに、大人をあんなに夢中にさせるものがあるということが、ひどく羨ましかった。

学校と家庭が連携して読書の機会を増やすのは、けっこうなことだと思う。ただ、機会を増やすより先に、大人が本を読んでいる背中を見せるほうが、たぶん話は早い。

## 例3：講演録（です・ます体／一人称「僕」／入口：依頼のされ方への違和感／脱線が本題／エンジンD、抜粋）

今日は保護者のみなさんに「子どもの自主性の育て方」についてお話ししてくださいと言われたんですけれど、僕はこの題を見て、ちょっと笑ってしまったんです（笑）。だって、「自主性を育てる」って、親が計画を立てて、そのとおりに子どもを「自主的に」させるっていうことでしょう？　それ、自主性なんでしょうか。

まあ、それはいいです。主催の方がいらっしゃる前なので、このへんにしておきます。

話は変わるんですけど、武道の稽古では「居着くな」ということをよく言うんです。居着くというのは、足の裏がべったり床に貼りついて、次の動きに移れなくなる状態のことです。おもしろいのは、人間がいちばん居着くのは、「こう動こう」と決めた瞬間なんですね。相手がこう来たらこう返す、と頭の中で決めると、身体はそのシナリオに貼りついてしまう。相手が少しでも違う動きをすると、もう間に合わない。

だから稽古では、決めないで待つ、ということを練習するんです。これがいちばんむずかしい。

……あれ、子育ての話をしに来たんでしたね（笑）。でも、話はそんなに逸れていないと思うんです。
