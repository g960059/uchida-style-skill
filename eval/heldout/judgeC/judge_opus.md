# 内田樹文体 真贋評価（judgeC / 12サンプル）

評価方針：7点以上は「熟読者がしばらく本人と区別できない」水準に限定。対比文型の回数は機械計測ではなく本文で数え直した。計測では拾えない偽装型の対比（「〜つもりで、じつは〜」「〜からといって〜わけではない。ただ」「〜と言われても〜ない。残るのは〜」）も数に含めている。

| 項目 | 点 |
|---|---|
| thinking | 6 |
| voice | 6 |
| structure | 5 |
| naturalness | 6 |
| substance | 5 |
| no_ai_smell | 5 |
| contrast | 7 |
| disclosure | 6 |
| overall | 6 |
| mistaken_for_real | 25% |

**展開マップ**
- P1：「燃えている」の比喩が倒錯していること（消しに来るのではなく薪を抱えて来る）／入口。比喩としてはよく効いている
- P2：常識（意地悪な連中の憂さ晴らし）を出し、「きまじめな怒り」「正義は飽きない」でずらす／常識→小転回
- P3：両説に共通する前提（矛先は相手に向いている）を疑う／転回の予告（約35%）
- P4：『十二人の怒れる男』第3陪審員の話／補助線。あらすじが長く、約330字ある
- P5：「人を叩く言葉は半分自分を向いている」／定式化（主張の明示は約58%地点）
- P6：規則への署名、呪いが自分を縛ること、叩く側の列に並ぶこと／含意・射程の拡大
- P7：火の番／冒頭の火の比喩の回収
- P8：生贄と集団の結束、くじ引き化／ここで新しい概念を持ち込んでいる（脱線に近い）
- P9：「許してもらえるはずだった場所を焼く」／着地

**対比文型**：3回
- 「意地の悪さはそれほど感じられない。目につくのは、むしろきまじめな怒り」：常識をずらす位置にあり、効いている
- 「怒鳴っていた相手は少年ではなかった…裁かれていたのは息子であり」：映画の種明かしとして必要
- 「相手を裁いているつもりで、じつは自分が…規則を書いている」：偽装型の対比。P5と言っていることが重なっており不要

**最も内田らしい箇所**
- 「火事なら、ふつうは人が消しに集まってくる。ネットの火事には、みんなが薪を抱えて集まってくる。」
- 「悪意ならそのうち飽きるが、正義はなかなか飽きない。」

**最も内田らしくない箇所**
- P7〜P9の三連続の短い決め台詞（火の番／生贄／許さない言葉）。どれも結論の言い換えで、決めポーズが続いて見える。とくに生贄の段は、終盤で初めて出てくる概念なのに回収されていない。本物ならジラールの名前を出して一段落かけて論じるか、出さずに火の番の一行で終える。

**展開マップ**
- P1：題の紹介と「粘土板」の冗談／入口
- P2：「いい大学…の話はしません」／常識を予防的に退ける
- P3：噺家の師匠は稽古代を取らず、恩は自分の弟子に返す／補助線（贈与）
- P4：返す相手がずれているから流れが止まらない、誰も借りを返し終えていない／補助線の中での定式化
- P5：「なんでこんな話をしたかというと」／橋渡し（ここは型どおり）
- P6：九九の作者は不明、ピタゴラスはもう死んでいる／卑近な場面に戻す
- P7：「しなければならない」は借りのある人の落ち着かなさであり、理由は過去の側にある／定式化（主張の明示は約75%地点）
- P8：「落語の話も誰かから聞いた…みなさんに渡しておきます」／回収と着地。話の内容をそのまま実演している

**対比文型**：2回
- 「いい大学に入って…というお話は今日はしません」：予防的な否定。導入として許容範囲
- 「理由は、みなさんの将来の側にあるんじゃなくて、もう済んでしまった過去の側にある」：一篇の転回点に一度だけ置かれていて、効いている

**最も内田らしい箇所**
- 「何百年も前にできた噺がいまだに寄席でかかっているのは、たぶん、誰ひとり借りを返し終えていないからなんですね。」
- 「お礼の言いようがないので、とりあえず、みなさんに渡しておきます。」

**最も内田らしくない箇所**
- 「人類が文字を発明した次の週くらいから…粘土板を前にして」。作り込んだ冗談で、漫談の掴みのように聞こえる。本物なら自分の中学時代や、ゼミ生に同じことを聞かれた話から入る。「お年玉」のたとえも高校生相手にしては幼い。論の骨格（反対給付義務と、学びの起点が過去にあること）は内田そのものだが、本人の持ちネタを手際よくまとめた模範解答の印象も残る。

- P6：成績が上がるとかえって仕掛けから出られない／含意
- P7：「勉強をやめてしまえ」という誤解を退け、途中でやめた弟子の失敗を挙げる／予防

- 「働き手を増やすことには成功したんですね。成功するとますます困るというのが、この話のおもしろいところです。」

**展開マップ**
- P1：「よくできた通信販売である」／whatを挑発的に先に出している（約3%地点）
- P2：制度の要約／原文の事実の保持
- P3：納税・寄附・買い物という三つの名前／鍵概念の導入
- P4：名前がずれると人は居心地のいい名前に沿って振る舞う、それで競争が過熱する／定式化（約35%）
- P5：「買い物には裏側がある」／一文の転回

**最も内田らしい箇所**
- 「税金というのは、もともと、自分が選んだわけでもない隣人の暮らしのために、品定めをせずに払うお金のことだったはずだ。」
- 「お礼の品を見比べてから決める応援というのは、日本語として少し無理がある。」

**最も内田らしくない箇所**
- 「長く続く制度にするには、設計を考え直す必要がある。」。原文の結論をなぞった答案の一文になっている。本物ならこの一文は省き、「何と呼ぶか」の話にいきなり入る。全体に補助線も脱線もない、清潔な時評コラムで、内田特有の寄り道（言葉の語源や、誰かの体験談）が欠けている。

## 共通する弱点（重要度順）

1. **同じ課題のサンプル同士で、結論と決め台詞がそろっている。並べて読むと量産品に見える。** h1の4本（S01/S07/S11/S12）は、入口と補助線を変えているのに、行き着く結論がすべて「叩く言葉は叩いた本人を縛り、降りられなくする」になっている。とくに次の一文はほぼ同文で三回出てくる。S01「人に向けた呪いの言葉は、言われた相手より先に、言った本人を縛りあげる」、S07「人に向けた呪いの言葉は、相手より先に、言った本人の足元を縛る」、S12「罵倒の言葉は、言われた人の未来といっしょに、言った人の未来も縛る」。そのほかにも次の重複がある。
   - 「規則に署名する／規則に一票を投じる」（S01/S07）
   - 雇用・仕事の比喩：「終身雇用」（S12）、「監督係を雇う、勤務時間の定めがない」（S11）
   - 「燃やす」と薪の比喩（S01/S07）
   - 両説が共有する前提を疑う転回（S01 P3／S07 P4）

   一本ずつ読めば悪くないが、四本並べると同じ鋳型から出てきたことがすぐわかる。

2. **h3講演の骨組みがテンプレート化している。** 題目を紹介して照れる → 「いい大学」論を予防的に退ける → 外部の補助線（落語／機内の医者／魔法使いの弟子） → 「なんでこんな話をしたかというと」（S02）・「なんで急に飛行機の話をしたかというと」（S05） → 科目名を列挙する（九九・分数・三平方／二次関数・古文・元素記号／歴史・国語・数学） → 定式化 → 自分の講演に触れる落ち（「あ、もう時間ですね」がS02とS05で同文。S03「今日の僕の仕事はうまくいったんでしょうか」、S08「講演者の出番は、このへんまで」）。四本とも、講演者自身の体験談（「僕が中学生のとき」「うちのゼミで」）が一つもない。本物の内田の講演は自分語りと脱線で膨らむので、この清潔さはかえって不自然に見える。

3. **h2では二つの鋳型に分かれている。** 「名前・言葉のずれ」型（S04「三つの名前」、S10「買ったと言う」）と、「気持ちの話から制度の話へ」型（S06・S09。どちらも冒頭で「地域を応援する気持ち」を引いて疑う）。しかも要約の段落（P2）を原文から塊で写していて、答案に近い（S06/S09/S10）。

4. **語彙と型の癖が全体に散らばっている。** 「厄介」（S05、S06、S08、S10、S11の5本）、「〜と呼びたい」（S08/S11）、「勘定」（S06/S07）、「たいへん」、一文段落の決め（「そして、買い物には裏側がある」「気持ちだけでは、この循環をほどけない」「けれども、その日はほんとうに来ないのだろうか」）。どれも一本の中では一度ずつしか出てこないので気づきにくいが、横断すると口癖のリストに見える。

5. **末尾で短い格言を重ねる。** S01（3連続）、S07、S12で、議論が着地したあとに一文段落の決め台詞を二つ三つ重ねている。内田の着地は短く、しばしば肩をすくめるような軽さ（「まあ、〜だろうけれど」）で終わる。決め台詞を連ねる終わり方は内田のものではない。S04とS10の終わり方は成功例。

6. **補助線を一回きりの例示として使い捨てている。** 『十二人の怒れる男』（S01）、笠地蔵（S06）、オオカミ少年（S12）、ほうき（S03）は、あらすじを長く語ったあと「これと同じだ」とつなぐだけで、後半で意味を変えて戻ってこない（S03の水、S07の二分、S10の神社は例外的に戻ってくる）。また、対比文型の機械計測値は全サンプルでほぼ0だが、実際には「〜つもりで、じつは」「〜からといって〜わけではない。ただ」のような偽装型の対比に置き換わっているだけのものがある（S01/S06/S08）。

## スタイルガイド（skill）への具体的な改善提案

1. **【追加】定番命題のローテーション規則。** 「呪いの言葉は言った本人を縛る」「贈与は返す相手がずれることで流れる」「自分のためなら、やらない自由がある」などの内田の定番命題は、一篇につき最大一つまでとする。使う場合は、その命題を格言の形で書かず、補助線の比喩のままで語らせる。格言の形（「〜は〜を縛る」）での使用は禁止する。
2. **【追加】同じ課題で複数本を書く場合の差別化チェック。** 書く前に「この課題で最初に思いつく結論」を書き出し、それを避けるか、少なくとも別の着地を選ぶ。h1なら「叩く側が自縛する」以外の主題（たとえば「謝罪という儀礼の失効」「見物人の快楽」）を候補として明示的に挙げさせる。
3. **【削除・禁止】講演の定型句。** 「あ、もう時間ですね」「なんでこんな話をしたかというと」「〜というお話は今日はしません」をガイドから例文として外し、使用を禁止するか一度に限る。橋渡しは言わずに飛ぶほうが内田らしい。
4. **【追加】講演録には自分の体験談を最低一つ入れる。** 「僕が〜だったとき」「うちの道場で」「ゼミの学生が」のような一人称の経験談を一つ入れ、それを補助線と絡ませる。科目名の三点列挙（九九・分数…）は禁止する。
5. **【修正】着地の規則。** 最後の三段落のうち一文段落は一つまで。最終段では主張を言い換えず、P1の場面か補助線の具体物（水、二分、カニ）に戻して終える。「〜なのである」で締める決め台詞の連打は禁止する。
6. **【追加】補助線の回収義務。** 補助線は登場後に最低二回戻し、二回目では意味を変える（反転させる、拡張する、話者自身に当てはめる）。あらすじの説明は全体の20%以内に収める。
7. **【修正】対比のカウント対象を広げる。** 「〜つもりで、じつは〜」「〜からといって〜わけではない。ただ〜」「AではなくB」「Aと言われてもBない。残るのはC」をすべて対比として数え、一篇で2回までとする。とくに「〜わけではない。ただ」は保険のための否定なので原則禁止。
8. **【追加】横断語彙の上限リスト。** 「厄介」「〜と呼びたい」「勘定」「仕事（比喩としての）」「律儀」について、一篇に一回まで、かつ毎回は使わないと明記する。概念に名前をつけるときは「仮に〜とでも呼んでおく」くらいの照れを入れる。
9. **【修正】書き換え課題での事実の扱い。** 原文の事実（控除、返礼品、財源、PR、競争の過熱、都市部の税収減）を第2段落に塊で要約するのを禁止し、論の進行に合わせて一つずつ拾わせる。原文の結論文（「大切にしながら〜検討することが重要」）は、だ・である体に移植せず、ずらすか皮肉で受ける。
10. **【追加】予防的配慮の削減。** 「傷つけられた当人が〜ことはある」「〜は入り口になりうる」のような、批判を避けるための留保の段落は一篇に一文まで。内田は留保するとき、自分を下げる自虐（「私などは早々に退場である」）で処理することが多い。
