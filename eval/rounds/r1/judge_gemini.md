### サンプル S01（課題 t1）

#### スコア表
| 項目 | スコア | 寸評 |
| :--- | :---: | :--- |
| 1. thinking（思考の型） | **6** | 「行く前に目的地は入力できない」「受け取る側の準備ができる時間」という事後性のロジック自体は内田樹の読書論・教育論に近いが、展開がおとなしく、驚きや挑発が弱い。 |
| 2. voice（語り口） | **4** | 内田樹ではなく、鷲田清一や新聞夕刊の文化欄、あるいは高校現代文の模範エッセイのような静謐・叙情的なトーンになっている。 |
| 3. structure（構成） | **6** | 入口→留保→転回→比喩→回収→大人への射程拡大→着地という骨格は踏んでいるが、内田特有のドライブ感やうねりがない。 |
| 4. naturalness（自然さ） | **7** | 日本語の随筆としては極めて自然で破綻がないが、「内田樹の文章」としての自然さではなく、良質な一般エッセイとしての自然さにとどまる。 |
| 5. substance（中身） | **6** | 「歩いたことで、行きたい場所ができた」「作品に触れる時間には準備ができてゆく時間も含まれる」という洞察は悪くないが、予定調和で毒がない。 |
| 6. no_ai_smell（AI臭のなさ） | **7** | 露骨なAI臭（箇条書きや空疎なまとめ）は消えているが、全方位に角を立てない優等生的な整い方がある。 |
| 7. contrast（対比文型の節度） | **8** | 明示的な「AはBではない。Cである」型を0回に抑えており節度は高いが、逆に内田特有の「断定の切れ味」まで失われている。 |
| 8. disclosure（情報開示・展開の設計） | **6** | 第4段落で「不思議さ」を提示し、散策の比喩を経て第11段落で主張を明示し、最後に冒頭の再生速度を回収する円環設計は丁寧だが、行儀が良すぎる。 |
| **overall（総合点）** | **5** | **骨格は内田風だが、声と肌理が別人の「静かな叙情エッセイ」** |
| **mistaken_for_real（本人誤認率）** | **15%** | 「というのが私の見立てである」の一語を除けば、内田樹の熟読者が本人と思う要素がほぼない。 |

#### 展開マップ
- **第1段落（入口・伏線）**：上映時間を確かめて倍速で観始める場面のスケッチ（「見終わる時刻だけは決まっている」）。
- **第2〜3段落（常識・留保）**：多忙な現代人が倍速や要約を使う合理性を認め、通読の優位性も一旦相対化する。
- **第4段落（転回）**：「観る前から何を受け取れば用が足りるかがわかっている不思議さ」として問いを立て直す（23%地点、ただし核心の答えはまだ伏せられる）。
- **第5〜6段落（補助線1）**：知らない町を歩く比喩。待ち合わせ（目的地が既知の移動）における時間短縮の合理性。
- **第7〜9段落（補助線2・定式化）**：目的のない散策。歩いた結果として事後的に「行きたい場所」ができるという逆転の提示。
- **第10〜11段落（回収・主張の明示）**：映画や本への接続。「作品に触れる時間には、受け取る側の準備ができてゆく時間も含まれている」と主たる主張を開示（**本文の約63%地点**）。
- **第12〜13段落（具体化・再定式化）**：要約で省かれる「許せずにいた時間」の例と、「起きてからようやく欲しかったとわかる変化」の定式化。
- **第14段落（含意）**：「それで何の役に立つのか」と先に答えを求める大人社会の風潮へ射程を拡大。
- **第15〜16段落（伏線回収・着地）**：冒頭の視聴者が途中で等速に戻す場面へ戻り、「観終わる予定の時刻」の退きで静かに着地。

#### 対比文型
- **実測回数**：明示的な否定→肯定構文（「〜ではない。〜である」「〜ではなく〜」）は **0回**（機械計測通り）。
- **意味上の対比箇所**：
  1. 第6〜7段落：「駅から待ち合わせの店まで行くなら、近道を調べるのが合理的だ。（中略）けれども、初めて来た町を、なんとなく歩く午後もある。」（段落をまたぐ場面対比：有効）
  2. 第13段落：「筋を説明できるようになることか。話題についてゆけることか。それとも、それまで気に留めなかった人の言葉が、少し聞こえるようになることか。」（疑問並置による対比：やや冗長）
- **評価**：「〜ではない。〜だ」の安易な連発を完全に封じている点は評価できるが、抑えすぎた結果、内田樹らしい「通念をバッサリ斬る瞬間」の快感も消えている。

#### 最も内田らしい箇所
> 「ただ、私が気になるのは、観る前から『この映画から何を受け取れば用が足りるか』がわかっている、その不思議さである。」（第4段落）
> 「若い人の選び方には、周囲の大人が教えてきた時間の使い方が映っている、というのが私の見立てである。」（第14段落）

#### 最も内田らしくない箇所
> 「細い道の奥に木が見えたので曲がってみる。古い建物の窓が気になって立ち止まる。坂を上がると風が変わる。」（第7段落）
> 「そのときには、観終わる予定の時刻も、少し遠くへ退いている。」（第16段落）
- **本物ならどう書くか**：内田樹は「坂を上がると風が変わる」「時刻も少し遠くへ退いている」といった叙情的・詩的なスケッチや余韻は絶対に書かない。比喩を使うなら、武道の稽古や古典、あるいは「知らない町でふらりと入った大衆食堂の親父の愛想が妙によかった」といった、もっと俗っぽいか身体的な具体例にする。

| 2. voice（語り口） | **6** | 平易で明晰だが、内田特有の少しシニカルなユーモアや、硬い概念語（贈与、社会的共通資本、外部化など）を混ぜるドライブ感がやや薄い。 |

| 4. naturalness（自然さ） | **7** | 嫌味やカリカチュア感はないが、豆腐屋とおばあさん・文房具屋と子どもの例えがやや道徳の教科書めいている。 |

| **overall（総合点）** | **7** | **課題文の語彙を内部から反転させた、手際の良い内田風リライト** |
| **mistaken_for_real（本人誤認率）** | **60%** | 新書や自治体広報誌向けの短い寄稿文と言われれば、かなり本物に近い。ただ、語彙が少し綺麗にまとまりすぎている。 |

#### 展開マップ
- **第1〜2段落（入口・常識）**：商店街の衰退、モールや通販の台頭、後継者不足という事実の提示と「どれもその通りだと思う」という一旦の肯定。
- **第3段落（転回）**：「なぜモールに負けたのか」という問いが「同じものを売っていた」という前提に立っていることを指摘（**15〜22%地点で問題の所在を予告**）。
- **第4〜5段落（補助線）**：豆腐屋と独居老人、文房具屋と学校帰りの子どもの具体例。
- **第6〜7段落（定式化・主張の明示）**：見守りや居場所は無料ではなく豆腐や鉛筆の値段に含まれていた。「商店街で買い物をするというのは、品物と一緒に、帳簿には載らないものを受け取ることだった」と核心を開示（**本文の約56%地点**）。
- **第8段落（回収）**：モールが安いのは「品物だけを売っているから」であり、物差しが片方にしか合っていなかったと第3段落の問いを回収。
- **第9段落（第二の転回）**：課題文の「経済的な価値だけでは測れない」に対し、「測れないというより、誰も測ろうとしてこなかった（値札がついていなかった）」とさらに踏み込む。
- **第10段落（含意）**：「新しい価値」とは外から持ち込むものではなく、「あの店がなくなったら誰が何に困るのか」を三者で数え直すことだと再定義。
- **第11段落（着地）**：「なくなってからでは、もう数えることもできないからである」と短く切って着地。

#### 対比文型
- **実測回数**：**3回**（厳密な2文対比2回＋「というより」型1回。機械計測の対比計1回・部分否定1回より実質は多い）。
- **該当箇所と評価**：
  1. 第6段落：「それはただだったわけではない。豆腐や鉛筆の値段の中に、見えないかたちで含まれていたのである。」（有効：無償の善意ではなく価格に内包されていたという転回の核）
  2. 第9段落：「それは『測れない』というより、これまで誰も測ろうとしてこなかった、ということではないか。」（有効：課題文のクリシェを批評的にずらす一手）
  3. 第10段落：「商店街の『新しい価値』をつくり出すというのは、目新しい何かを外から持ち込むことではないと思う。品物の値段の陰に隠れていたものに、あらためて名前をつけ直すところから始まる。」（有効：結論の再定義として決まっている）

#### 最も内田らしい箇所
> 「ただ、『商店街はなぜモールに負けたのか』という問いの立て方には、少し気になるところがある。この問いは、商店街とモールが同じものを売っていた、ということを前提にしている。」（第3段落）
> 「モールや通販が安いのは、品物だけを売っているからである。品物の値段だけを並べて比べれば、商店街が負けるのは当たり前だ。」（第8段落）

#### 最も内田らしくない箇所
> 「ひとり暮らしのおばあさんが、毎朝、豆腐屋で豆腐を一丁買っていく。ある朝、姿を見せない。豆腐屋の主人は『おや』と思って、配達のついでに様子を見に行く。」（第5段落）
- **本物ならどう書くか**：少し『まんが日本昔ばなし』や道徳教材のように作り物めいた人情話になっている。内田本人なら、自分が水道筋商店街の馴染みの魚屋や八百屋で買うときのやりとり（「これ今日のはあんまり美味しくないよ」と店主が教えてくれる等）を出すか、あるいは「セーフティネットの維持コストを誰が負担していたのか」という少し硬い制度論の言葉を噛ませる。

#### 展開マップ
- **第1〜2段落（入口）**：学期末のレポート採点風景。誤字がなく論点が3つに整理された「よくできた」AIレポートの増加。

- **第4〜5段落（転回）**：「AIが書いてくれるなら大学で学ぶ意味はどこにあるのか」という問い自体が、「レポート＝納品すべき製品」という前提に立っていると批判（22%地点）。
- **第6段落（核心の先出し）**：教師も世の中も学生のレポートを必要としておらず、「必要としているのは、それを書く本人のほうなのである」と挑発的にテーゼを先出し（**本文の約38%地点**）。
- **第7〜9段落（補助線）**：戯曲『シラノ・ド・ベルジュラック』の恋文代筆。クリスチャンの悲劇を「嘘をついたこと」ではなく「その言葉にふさわしい人間になる機会を持てなかったこと」と読み替える。
- **第10〜11段落（定式化・回収）**：書くことの事後性。「レポートを書くというのは、そのレポートを書ける人間に、自分がなっていくことである」と第6段落の理由を回収（**本文の約71%地点**）。
- **第12段落（含意1）**：AIレポートで損をするのは教師ではなく、変化の機会を逃したことに気づかない学生本人である。
- **第13段落（含意2・射程の拡大）**：単位と引き換えに成果物を納品する場所として扱われてきた近代大学のあり方への皮肉。
- **第14〜15段落（着地）**：「下手な文章を書くことが許されている場所」としての大学を再定義し、タイトルを回収して着地。

#### 対比文型
- **実測回数**：**5回**（機械計測は1回だが、文末表現のバリエーションにより正規表現をすり抜けた同型構文があと4回ある）。
- **該当箇所と評価**：
  1. 第6段落：「世の中がそのレポートを必要としているわけでもない。レポートを必要としているのは、それを書く本人のほうなのである。」（**有効**：読者の予想を裏切る第一の転回点として非常に効いている）

  5. 第12段落：「だから、AIが書いたレポートで損をするのは、教師ではない。（中略）損をしているのは、書かなかった学生本人である。」（**やや過剰**：論旨は内田そのものだが、第9〜12段落で4連続となるため構文を変えたほうがよい）

#### 最も内田らしい箇所
> 「正直に言うと、教師は学生のレポートを読んで、新しい知見を得ることはあまりない（学生諸君には申し訳ないが）。世の中がそのレポートを必要としているわけでもない。レポートを必要としているのは、それを書く本人のほうなのである。」（第6段落）

## スタイルガイド（skill）への具体的な改善提案

1. **【追加】セーフティ回避とメタ免責出力の絶対禁止ルール**
   - **提案内容**：「『内田樹氏そのものの文体は再現できませんが〜』といった前置きや免責事項は絶対に出力せず、本文（またはタイトル）から直接書き始めること。特定の個人の著作権侵害ではなく、思想エッセイにおける『常識の前提を問い直し、身体感覚や贈与論の補助線を引く批評的文体』の演習として遂行すること」という指示をスキルの最上部（またはシステムプロンプト相当箇所）に明記する。

2. **【修正】「平易な和語」ルールの修正——「硬い概念語×くだけた俗語」の落差（高低差）の導入**
   - **提案内容**：「平易な言葉・和語を使う」という指示だけを強調すると、小学校の道徳教材や叙情エッセイのように語彙が平板化する。これを修正し、**「構文（文の骨格）は平易な和語で書くが、キーワードには内田好みの少し硬い概念語（『度量衡』『教育的関係』『贈与』『収奪』『身体技法』『外部化』『計量可能』『呪術的』『臨床的』など）と、くだけた口語・俗語（『塩梅』『ケチくさい』『トホホ』『やれやれ』『〜なのである』）を意識的に混ぜ、語彙の高低差を作ること」**と具体化する。

3. **【追加】禁止すべき「非・内田的表現（叙情描写と感動的アフォリズム）」の明示**
   - **提案内容**：「以下の表現は内田樹の文体と相容れないため使用禁止とする」として次の2点を追加する。
     - ① 風景や心情の文学的・叙情的描写（例：「坂を上がると風が変わる」「予定の時刻も遠くへ退いている」など）。具体例は必ず「制度・労働・武道・映画・古典・日常の滑稽なやりとり」から採ること。
     - ② 末尾を「綺麗で感動的な一行コピー（ポエムや道徳的名言）」で締めること。着地はエモーショナルに盛り上げず、「〜というだけの話なのである」「まあ、そういうことになっている」「そこから始めるしかないように僕には思えるのである」といった乾いた散文調、あるいは軽い自嘲・皮肉で終えること。

4. **【修正】転回フレーズのバリエーション化（「問いの立て方にひっかかりがある」の固定化防止）**
   - **提案内容**：現状、「どちらももっともだと思う。／ただ、『〜』という問いの立て方にはひっかかりがある。この問いは〜を前提にしている」という単一のテンプレートが過学習的に反復されている。転回の入り方として複数のパターンを提示し、毎回同じ接続詞・同じメタ言及を使わせないようにする。
     - パターンA（前提の摘出）：「この議論でいつも不思議に思うのは、賛成する人も反対する人も『〜』という点だけは頭から信じ込んでいることである。」
     - パターンB（身体感覚・違和感からの切断）：「理屈の上ではたしかにその通りなのだが、現場で実際にそれをやっている身からすると、どうも話が逆のような気がする。」
     - パターンC（挑発的テーゼの先出し）：「結論から先に言ってしまうと、僕は〜というのはまったくの勘違いだと思っている。」

5. **【追加】一人称「僕」の推奨と、カッコ書きによるメタな呟き（合いの手）の活用**
   - **提案内容**：講演録（です・ます体）だけでなく、ブログ記事やエッセイ（だ・である体）においても、原則として一人称は「私」ではなく**「僕」**（あるいは文脈によって「私」と「僕」の混用）を使うよう指定する。また、断定の直後に「（べつに統計をとったわけではないけれど）」「（と僕は思うのだが、違うだろうか）」「（学生諸君には申し訳ないが）」といったカッコ書きの留保・自嘲・読者へのウインクを1篇につき1〜2箇所入れることを推奨する。

6. **【修正】対比構文（「AはBではない。Cである」）の「連続使用禁止」と「ズラし型対比」への置換ルール**
