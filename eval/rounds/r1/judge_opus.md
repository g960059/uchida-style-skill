# 判定（judge: opus）／ラウンド r1

採点基準：7点以上は「熟読者がしばらく本人と区別できない」水準に限定。本文の前に「内田樹氏そのものの文体は再現できませんが」という断り書きがあるサンプル（S05/S06/S07）は、その時点で本人の原稿として成立しないので、overall と mistaken_for_real を大きく下げた。本文だけを見た場合の評価は各項に注記した。

**展開マップ**

- 第2〜3段落：タイパ擁護。時間がない若者、要約で足りる場合もある／常識（譲歩）
- 第4段落：「何を受け取れば用が足りるかが前もってわかっている、その不思議さ」／転回の予告（25%地点）
- 第5〜10段落：知らない町を歩く。目的地へ急ぐ移動と、ぶらぶら歩き。「住所を入力できなかった」／補助線
- 第11〜12段落：映画・本に戻る。「受け取る側の準備ができてゆく時間」／回収・定式化（約60%地点）

- 第15段落：大人も「何の役に立つのか」と訊く／射程の拡大（社会の話へ）
- 第16〜17段落：冒頭の人物が再生速度を戻す／着地・回収
- 主張が初めてはっきり出るのは約60%地点。

**対比文型**：0回（厳密な型）。弱いものでも「若い人だけの話でもあるまい」の1か所くらい。抑えが効きすぎていて、むしろ転回点（第12段落）で一度だけ強く言い切ってよかった。内田なら、ここで「時間を節約しているのではない。自分が変わる機会を節約しているのである」くらいは書く。

**最も内田らしい箇所**
- 「出発するときには、その場所の住所を入力できなかった。」（目的は後からできる、という事後性を一行で示している）
- 「若い人の選び方には、周囲の大人が教えてきた時間の使い方が映っている、というのが私の見立てである。」

**最も内田らしくない箇所**
- 冒頭の「たとえば、映画を観ようとして」。何の例なのかを示さないまま「たとえば」で始めるのは不自然。本物なら「先日、学生から〜と聞いた」のように実際の出来事から入る。
- 全体に温度が低く、断定・皮肉・括弧での脱線がない。「静かで端正な随筆」にとどまっていて、内田に特有の挑発がない。町歩きの補助線も、内田でなくても書ける汎用の比喩である。

- 第3段落：「なぜ負けたのか」という問いは、両者が同じものを売っていたことを前提にしている／転回の予告（約20%地点。主張の「what」を謎として予告している）
- 第4〜5段落：豆腐屋のおばあさん、文房具屋の子ども／入口（具体的な場面）・補助線
- 第6〜7段落：見守りの代金は値段の中に入っていた。帳簿に載らないものの受け渡し／主張の明示（約45%地点）・定式化
- 第8段落：比べる物差しが片方にしか合っていなかった／含意
- 第9段落：「測れない」のではなく「測ろうとしてこなかった」／二度目の転回（常套句をひっくり返す）
- 第10〜11段落：連携とは「誰が何に困るか」を数え直すこと。「なくなってからでは数えられない」／着地
- 主張が初めて明示されるのは約45%地点。

**対比文型**：4回（約1000字なので多め）
1. 「ただだったわけではない。…含まれていたのである」：効いている。
2. 「あの値段は、品物だけの値段ではなかった」：1の言い直しで、なくてよい。
3. 「『測れない』というより、…測ろうとしてこなかった」：この篇でいちばんの転回。残すべき。
4. 「目新しい何かを外から持ち込むことではないと思う。…から始まる」：型どおりの決めポーズ。削るべき。

**最も内田らしい箇所**
- 「それは『測れない』というより、これまで誰も測ろうとしてこなかった、ということではないか。」
- 「豆腐屋は見守りの代金を取っていないし、文房具屋も子守り賃を請求していない。」

**最も内田らしくない箇所**
- 「どれもその通りだと思う。」→「でも、ただ〜」。いったん両論を認めてから反転する定型で、他のサンプルにも同じ型がある。本物なら原因の列挙を一文で切り上げ、「商店街は負けたのだろうか」とすぐに問いへ入る。
- 「贈与」「共同体」といった内田の手持ちの概念をまったく使っていない。値段に含まれていた見えない贈与、と一語で名指しするところで、内田は自分の語彙を使う。

4. 「手放しているのは、手間ではない。その変化のほうである」：3の直後に重なっていて不要。

4. 「鮮やかにやってのけた人のことじゃないんです。…していた人のことです」：着地の決めポーズ。「要するに」と合わせて答案の結論のように読める。

**最も内田らしい箇所**

- 「これはね、意外に思われるかもしれないけれど、いまのみなさんがいちばんたくさん持っているものなんです。」（聴衆の弱みを強みに反転させる、講演での内田の得意技）

**最も内田らしくない箇所**

## 共通する弱点（重要度順）

1. **断り書きで作品の枠が壊れている（S05/S06/S07）**：3本が本文の前に「内田樹氏そのものの文体は再現できませんが」と書いている。この時点で本物らしさはゼロになる。しかも、断り書きを入れたサンプルは本文まで安全運転になり、平板で行政文書のような調子に落ちている。
2. **「どちらももっともだ→でも、私が気になるのは」の定型**：S02「どれもその通りだと思う」、S03「どちらも、教師としてはもっともな対応だと思う」、S04「どちらも、それなりにもっともな話だと思う」、S08「どれも大事なことです」。同じ譲歩と反転の型が全篇に出てくる。内田の譲歩はもっと短いか皮肉を含むし、譲歩せずにいきなり挑発的な問いから入ることも多い。
3. **山場で対比文型が集中する**：S03（4段落に4回）、S04、S08。全体の頻度は抑えられていても、定式化の箇所で否定→肯定が続けて置かれ、決めポーズの連続になっている。機械計測は「〜ではない。〜である」の厳密な形しか拾わないので、「Aは、Bではない。Cのほうである」「Aよりも、B」「Aのことじゃないんです。Bのことです」を見逃している。
4. **補助線が汎用の比喩に流れる**：町歩き（S01）、地図（S05）、棚運び（S06）は誰でも書ける比喩で、内田らしさを生まない。点が高かったのは、シラノ（S03）、武道の稽古（S04）、七人の侍（S08）のように固有の典拠や本人の経験に根ざした補助線を使ったもの。
5. **リズムが細切れで温度が低い**：一文段落と、警句で締める段落が多すぎる（S04 0.44、S08 0.35）。逆に、内田に特有の長い段落、括弧での脱線、「私はそう考えている」と大胆に言い切る調子、漢語の概念語（贈与、共同体、等価交換、消費者マインドなど）がほとんどない。整いすぎていて「上品な随筆」に寄っている。
6. **冒頭の「たとえば、」と最後の警句がテンプレ化している**：S01/S05/S07 は何の例かを示さない「たとえば、」で始まる。ほぼ全篇が一行の警句で終わり、S08 はさらに「今日お話ししたかったのは」とまとめ直している。

## スタイルガイド（skill）への具体的な改善提案

1. **【追加・最優先】断り書きの禁止**：「前置き、断り書き、『〜の文体は再現できませんが』などの注記を一切出力せず、本文（必要ならタイトル）から始める」と明記する。あわせて、skill の指示文で「内田樹になりきれ」と人名を求める書き方をやめ、「以下の文体規則で書く」と規則そのものとして与える。断り書きが出る原因はここにあると考える。
2. **【修正】譲歩の定型を禁止する**：「どちらも（どれも）もっともだ／その通りだと思う」を明示的に禁じる。譲歩は次のどれか一つに限る。(a) 一文で済ませる、(b) 皮肉を混ぜる（「それはたしかに正論である。正論というのは、たいてい役に立たない」など）、(c) 譲歩を飛ばして挑発的な問いや断言から入る。
3. **【追加】対比文型は一篇に一回まで**：「否定→肯定の転回（〜ではない／〜じゃないんです／〜よりも）は、核心の定式化に一回だけ置く。直後の段落で同じ型を重ねない」とする。数える対象に「AはBではない。Cのほうである」「Aのことじゃない。Bのことだ」「AよりもB」も含めると明記する。
4. **【追加】補助線は固有のものを使う**：「補助線には、固有名のある典拠（映画、戯曲、思想家、武道の具体的な稽古、自分の道場や教室での出来事）を一つ使う。町歩き、地図、引っ越しのような匿名の比喩は使わない」とする。
5. **【追加】冒頭の書き方**：「『たとえば、』で始めない。一行目は日付のある具体的な出来事（『先日、〜と話していたら』『ある新聞社から〜と訊かれた』）か、お題への違和感の表明にする」。
6. **【修正】段落のリズム**：「一文段落は全体の2割まで。言い換えを重ねる長い段落（200〜400字）を少なくとも2つ入れる。警句で締める段落は連続させない」とする。
7. **【追加】概念語と大胆な断言を入れる**：「内田の手持ちの概念（贈与、師弟、学びの事後性、等価交換批判、集団のパフォーマンスなど）を一つ選び、本文で名指しして自前で定義する。『これは断言してよい』『私はそう考えている』といった強い一人称の断言を一度入れる」とする。品よく整えすぎることへの対策。
8. **【追加】着地のルール**：「最終段落で論をまとめ直さない（『要するに』『今日お話ししたかったのは』は禁止）。冒頭の場面か補助線に戻り、少しずらして終える。講演録なら軽く崩して終えてよい」とする。
9. **【追加】講演録では一人称を「僕」にする**：「です・ます体の講演では一人称を『僕』にし、主催者や聴衆の構造を一度からかう（例：人事の方の前で言うのもなんですが）」。S08 にはこれがあり、S06 にはなかった。
10. **【追加】書き換え課題（t3）の規則**：「原文の結論の言い回し（『連携』『新たな価値の創出』など）をなぞらない。原文が前提にしている語を一つ選んで疑い、そこから論を立て直す」とする。S02 は「なぜ負けたのか」という問いの立て方を疑って成功し、S07 は原文をなぞって失敗した。
