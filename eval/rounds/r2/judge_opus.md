# 評価 r2（judge: opus）

総評：8本とも破綻はなく、補助線の選び方（ツケ、漢文訓読、芝浜、『生きる』）には内田的な勘がある。しかし8本を並べると、骨格・決め台詞・括弧ユーモア・着地の仕掛け・結論の方向まで同じ型で、量産品であることが透けて見える。単体で読めば「内田風の上手なコラム」だが、熟読者がしばらく本人と取り違える水準（7点以上）に届いている篇はない。

## 共通する弱点（全サンプル横断、重要度順）

1. **8本が同じ骨格で書かれていて、量産品に見える。** ほぼ全篇が次の順で進む。(a) 小さな物や場面（余白の「？」、丸椅子、お水、再生速度の欄、ノートの端）→ (b) 課題の常識を公平に要約し、「気持ちもわかる」「筋の通った理屈がある」と理解を示す → (c)「ただ」「でも」で前提を指摘 → (d)「少し離れた話をする」「話が少し遠回りになるが」「少しピアノの話をします」で補助線を一本 → (e) 補助線を本題に一対一で当てはめる → (f)「Xと呼んでおこう」「Xというのは」で概念を自前で定義 → (g)「〜ではなく〜」で定式化し、断言を宣言する → (h) 評価する側・制度の側に矛先を向ける → (i) 冒頭の物に戻って余韻の一行で閉じる。冒頭の物に戻る円環の着地は8本中8本。開示のタイミングも、主張の明示がほぼ全篇60〜65%地点にそろっている（例外はS03の先出しとS05の75%）。一本ずつなら「設計」に見えるものが、並べると「型」になる。内田本人の文章は、もっと形がばらばらである。
2. **断言を予告する定型句が8本中8本にある。** 「私はそこは断言できる」（S01）、「私は…無理だと考える」（S02）、「ここは迷わずに言っておく」（S03）、「これは断言します」（S04）、「私はそう考えている」（S05）、「ここははっきり言っておきたい」（S06）、「これは断言してよいと思う」（S07）、「僕はこの点は、はっきり言っておきたい」（S08）。断言と留保のバランスというスタイル指示を「断言を一回宣言せよ」と機械的に実装した跡に見える。内田は断言するとき、断言だと予告しない。
3. **結論が同じ方向に収束している。** 「帳面・採点・勤務表・計画書に載らないもの／数えられない働き」がS01・S02・S03・S04・S06・S08の6本で核か準核になっている。最終盤で「評価する側の問題」に矛先を向ける段落も、S01・S04・S05・S06・S08の5本にある。課題が違っても同じ洞察に着地するので、内田の論点の幅（贈与、師弟、辺境性、身体知、呪い、学びの主体の変容、集団的知性）の一部しか使われていない。
4. **括弧のユーモアが一篇に一つずつ「配給」されている。** 「（ありがたいのだけれど）」「（善意には定休日さえつけにくい）」「（私自身…文句を言える立場ではない）」「（これは大人にもけっこう身に覚えがある）」「（私もここで一度、納得しかけた）」。講演録2本は「（笑）」と「人事の方」いじりが両方にある。ユーモアの出る位置も量もそろっていて、自然に出たものに見えない。
5. **語り口が抑えられすぎて平板。** 品の良いコラムニストの文体で、内田特有のものが乏しい。たとえば話を大きく広げる大風呂敷、「〜なのである」「〜ではないか」「というのが私の仮説である」で議論をたたみかける調子、長い段落で同じことを角度を変えて三度言う螺旋、レヴィナスや武道など思想家・身体知の固有名が不意に入ること、「話を戻す」で脱線を認める身ぶり。段落の長さもほぼ均一（一文段落率0か0.25）で、リズムの起伏がない。最初の一手で挑発的な「what」を出すのはS03だけ。
6. **補助線が議論を生まず、図解で終わっている。** S01（陪審員→教室）、S02（消防→商店）、S06（仮縫い→鑑賞）、S08（譜めくり→資料）は、補助線と本題の対応関係を説明する段落が続く。補助線そのものの中で予想外の反転が起きない。S06は対応自体が混線している。補助線の中で論が一度ひっくり返っているのは、S03のツケ（→モールは割り切れなさを除去した）、S05の訓読、S07の芝浜だけである。

## スタイルガイド（skill）への具体的な改善提案

1. **【削除・禁止】断言の予告句を禁止する。** 「ここははっきり言っておく」「これは断言する」「私はそう考えている」を、決めの文の直後に置かない。断言は文の強さ（「〜に決まっている」「〜なのである」）と、前後の論証で示させる。
2. **【修正】冒頭の物に戻る着地を必須から外す。** 円環構成は「使ってよい型の一つ」に格下げし、着地の型を複数並べて選ばせる。たとえば「抽象的な一文で突き放す」「新しい問いを投げて終える」「時事や私事への脱線で唐突に切る」「『というようなことを考えた』で閉じる」「講演なら時間切れで論の途中で切る」。冒頭の小道具を最終行で回収する技巧は、多くても2本に1本までにする。
3. **【追加】開示のパターンを三つ以上用意し、課題ごとに一つを選ばせる。** (A) 暴論の先出し型：冒頭20%以内に「乱暴なことを言うようだが」で what を出し、why を引っぱる（S03型）。(B) 脱線が本題だった型：長い脱線のあとで主張を明かす（S04、S05型）。(C) 二段反転型：常識を一度ひっくり返して読者を納得させ、その反転も同じ前提に乗っていたと示す（S07型）。主張の明示位置が毎回60%前後にそろわないようにする。
4. **【削除】第2段落の「公平な常識要約＋理解の表明」のテンプレを外す。** 「気持ちもわかる」「筋の通った理屈がある」のような譲歩を入れる義務をなくす。常識は一文で戯画化して捨てるか、本文の途中で敵役として出せば足りる。
5. **【追加】結論の方向に多様性を持たせる。** 「数えられない／評価制度に載らないもの」と「評価する側への矛先反転」は、一篇の核にしてよい場合を限る指示を入れる。かわりに、内田の論点ストック（贈与と反対給付、師弟と学びの事後性、辺境人の学び方、身体と時間、集団的知性、呪いと祝福、消費主体の幼児化）を列挙し、課題ごとに一つを選んで深掘りさせる。
6. **【修正】補助線の扱いを変える。** 「補助線を一本引き、本題に当てはめる」から「補助線の内部で一度、予想外の反転を起こす」に書き換える。補助線と本題の対応を説明する段落は一つまでにする。導入句（「少し離れた話をする」等）は付けず、いきなり話し始め、後で「なぜこんな話をしたかというと」と回収するほうを推奨する。
7. **【削除】括弧ユーモアのノルマをやめる。** 括弧の自己ツッコミは一篇0〜1回の任意にする。ユーモアは誇張、自分を笑う一言、言葉尻をつかまえることなど、本文の論理から出るものを優先させる。講演録では「（笑）」を2回までにし、「人事の方」のような聴衆の誰かをいじる手を定型にしない。
8. **【追加】語彙と段落の幅を広げる。** 「〜なのである」「〜ではないか」「というのが私の仮説である」「話を戻す」「私見によれば」を、とくに論の加速部分で使えるようにする。思想家・武道・能楽などの固有名を、必然性がある場合に限って一回入れてよいことにする。同じ主張を角度を変えて三度言い直す長い螺旋段落を一つ入れ、すぐ後に短い一行段落を置いて落差をつける。段落長がそろうことをAI臭の指標として明記する。
9. **【追加】両論併記で論の勢いを止めない。** 「〜だけから判定するのは難しい」「〜とも言える」のような公平さのためのバランス取りを禁止事項に入れる（S06¶8）。内田は一方に寄せて押し切り、留保は「たぶん」「と思う」の語尾で済ませる。
10. **【修正】決めの一段落（独立した一〜二文の対比文）は一篇0回を標準にする。** 「失われるのは〜ではない。〜である。」を独立した段落に置くと決めポーズになる（S03¶6、S07¶9）。対比文で定式化するなら、論証の段落の末尾に溶かし込む。
