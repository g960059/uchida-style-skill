# r3 文体評価（judge: opus）

評価対象：judge_bundle.md の S01〜S08（課題 t1〜t4 各2本）
採点方針：7点以上は「熟読者がしばらく本人と区別できない」水準に限定。対比文型は機械計測を参考にしつつ、「〜ではなくて」「〜であって、〜ではない」「AよりもBにある」のような言い換え型も含めて数え直した。

- P8：「自由に選べる社会がよい」と書いた学生と、家族の事情を話す同級生／適用（作り例で、道徳の教材めいている）
- P9：AIの文章にも問いが向け直される。「問いから退席しきれない」身分／定式化
- P10：割の悪い話。教員も安全ではない／含意
- P11：社会は答えを早く出す人を欲しがる。残り時間がむき出しになる／着地（総括型）
- 主張の初出：約80%地点（P9）。

**対比文型**：2回（機械計測は0回）。
- 「答案の製作者であることより、自分に向け直された問いの宛先であり続けること」：「ではなく」を「より」に置き換えた対比。定式化の位置にあるが、抽象語が並ぶので決めポーズに見える。
- 「真相に近づくことと、安心してものを言えるようになることが、見事に反対向きに進む」：対比というより逆説。効いている。

**最も内田らしい箇所**
- 「四年間かけて『確かにご本人でした』と証明するのも、ずいぶん大がかりな話だ。」

**最も内田らしくない箇所**
- 冒頭の「口頭試問」が最後まで回収されない。いちばん面白い入口が捨てられている。本物なら最後に「口頭試問は、だから試験ではなくて授業そのものなのである」というように、意味を変えて戻ってくる。
- P11「社会は、答えを早く出せる人を欲しがる。……むき出しになるのだと思う。」：社会への一般論で総括して終えている。AI的な締め方。

## 共通する弱点（重要度順）

1. **8本が同じ鋳型から出てきたように見える（量産品の印象）。** 並べて読むと、骨格がほぼ同じである。
   - 骨格：語への小さなひっかかり、または卑近な場面 → 世間の常識 → 有名な作品・昔話・競技の筋を一つ紹介（笠地蔵／モダン・タイムス／落語／ツケ／アポロ13／「自由」の訳語／サッカー／オイディプス）→ 直後に「ところが」 → 一文だけの段落（「笑って観ていられる場面だ」「困った勉強もあったものである」「困りますね」「AIの書くレポートには、この隙間がない」「画面に映っていない人が、点を取らせている」「笑う暇がない」「月末の支払いがある」）→ 約70〜85%地点で定式化 → 問いか回収ギャグで着地。
   - 補助線はどれも「一篇に一つ、他人の作品の筋をまとめて紹介する」形式に揃っている。内田本人の文章で頻繁に出てくる一人称の経験（合気道の稽古、能の舞台、大学の教授会、家族）が8本中S06の一部にしかない。
   - 主張を明かす位置も、ほぼ全部が70〜85%帯に固まっている。S03の「what を先出しする」型が唯一の例外。
2. **同じ課題の2本が同じ洞察に収束している。**
   - t4：S05「その人が休むと、急にあちこちで仕事が止まる」とS07「その人が休んだ日にだけ、職場のあちこちで小さな詰まりが起きる」は、ほとんど同じ文である。どちらも「隙間・空き地を作る見えない人」という同じ結論。
   - t3：S01とS04はどちらも「見守り＝清算されない関係の副産物」。
   - t1：S02とS03はどちらも「時間を借金・費用として数える会計の感覚」。
   - 補助線は違うのに、着く先が同じになっている。
3. **会計の語彙と温度調整の語彙が全サンプルで共通している。**
   - 会計語彙：「勘定」「清算」「帳尻」「取り分」「割の合わない／割の悪い」「計上」「督促」「借金」が、ほぼ全篇に出てくる。
   - 温度調整語：「ずいぶん〜」「なかなか〜」「たいへんなことである」「〜もあったものである」「むき出しになる」「たぶん」。
   - 個々の文では自然でも、8本を並べると同じ書き手の癖というより、同じ指示書の痕跡に見える。
4. **着地が問いの形に偏っている。** S01・S02・S04・S05（さらにS08も半ばそう）が、問いや開いた余韻で終わる。内田の結びは、短い断定、自嘲、「というのが私の暫定的な結論である」といった形が多い。問いで閉じる型ばかりが続くと、「答えを閉じない」というルールを機械的に適用した結果に見える。
5. **対比文型を抑えすぎた結果、代わりの型が出てきている。**
   - 明示的な「AではなくB」はほぼ消えた。その代わりに次のような言い換え型が、定式化の位置に繰り返し現れる。
     - 「AよりもBにある」（S02）
     - 「Aであることより、Bであり続けること」（S08）
     - 「AであってBではない」（S03、S06）
   - 機械計測はこれらを取りこぼしている。
   - 数を抑えること自体はいいが、転回点で一度きっぱり言い切る力がなくなり、どの篇も同じ低い声で進む。
6. **内田らしい「大胆さ」と「散らかり」が足りない。**
   - 整いすぎていて、品がよい。思想家の名前（レヴィナス、モース、ラカン）や自説の参照（「前にも書いたことだが」）、「話が逸れた」といった脱線の自覚、「これは断言してよい」という強い断定がほとんどない。
   - 講演録（S05、S07）は書き言葉の論証を話し言葉の語尾で包んだもので、ライブ感が薄い。

## スタイルガイド（skill）への具体的な改善提案

1. **補助線の形式を回し、毎回同じにしない。** 「有名作品の筋紹介を一つ」を既定にしない。少なくとも次の三系統から選ばせ、同じ課題の2本目では別の系統を使うよう明記する。
   - 一人称の経験（武道・能・教室・家族）
   - 思想家・学説の名指し（モース、レヴィナスなど、一篇に一人まで）
   - 作品・昔話
2. **作品の筋紹介を圧縮する。** 補助線の筋紹介は全体の20%以内とし、要点に入るまでを2文以内にするルールを加える（S05とS08は筋の説明で間延びしている）。
3. **補助線の直後に一文段落を置く癖を禁じる。** 一文段落は一篇に1回までとし、「補助線の直後」には置かないことを明記する。今は全サンプルで同じ位置に置かれていて、指紋のようになっている。
4. **着地の型を分散させる。** 「問いで終わる」を既定にしない。候補は次のとおりで、問いで閉じるのは一篇おきに一度以下に制限する。
   - 短い断定
   - 自嘲
   - 冒頭の場面へ戻して、その意味を変える
   - 「暫定的な結論」と明示する
5. **言い換えの螺旋を標識に頼らせない。** 「言い換えれば」「もう一歩言えば」「さらに厄介なのは」の連鎖を禁じる。言い換えは標識なしに語をずらして行わせる（S01、S05）。
6. **対比文型の規定を修正する。** 「0回を目指す」のではなく、「転回点で1回、きっぱり使う。それ以外では、〜より〜／〜であって〜ではない／〜だけでなく といった言い換え型も対比として数え、合計2回以内」とする。言い換え型で数をごまかすことを明示的に禁じる。
7. **共通語彙の使用を制限する。** 「勘定・清算・帳尻・割に合わない・むき出し・ずいぶん・たぶん」を高頻度語リストに載せ、一篇につき各1回までとする。会計の比喩は、課題が経済に関わる場合（t3）に限る。
8. **2本目では別の洞察を立てさせる。** 同じ課題の2本目では、1本目の結論を先に書き出させ、それとは別の結論にたどり着くよう明示する（S05とS07の収束を防ぐ）。
9. **講演録にライブの要素を義務づける。** 講演録（です・ます体）では、次のうち3つ以上を入れさせる。
   - 聴衆への呼びかけ（「みなさん、そうでしょう」）
   - 自分の脱線への言及
   - 同じ要点の繰り返し
   - 時間超過で早口になる
   - （笑）
   - 加えて、書き言葉の論証段落（「言い換えると」で始まる段落）を禁じる。
10. **書き換え課題（t3）では、原文の事実を論の中に溶かし込ませる。** 冒頭近くで事実を列挙したり、原文の結論を前置きしたりしない（S01のP2）。原文の事実一つ一つを「論の中で意味を変えて再登場させる」こと（S04の方式）を手本として示す。
