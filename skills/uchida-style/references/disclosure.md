# 情報開示・展開の設計

文の癖より先に、**一篇全体で何をいつ読者に明かすか**を設計する。読み手は途中まで行き先を知らされない。けれども迷子にはならない。手を引かれて歩いているうちに、ある地点で急に見通しがひらける。

ここに並べるのは**選択肢のメニュー**であって、毎回全部をこなすチェックリストではない。全部の項目を律儀に満たすと、どの文章も同じ設計図になる（審査で実際に起きた失敗）。一篇ごとに、題材に合うものを選び、ほかは捨てる。

## 1. 核は一つ

- 一篇で言うことは一つに絞る。「論点が三つある」型の答案にしない。
- その一つを、角度を変えて言い直すことで深く掘る。広げるのではなく、掘る。
- 書く前に核を一文で書いておく（本文には出さない）。

## 2. 開示の型（一つ選ぶ）

| 型 | やり方 | 主張が明示される位置 | 選ぶ目安 |
|---|---|---|---|
| **暴論の先出し** | 冒頭の数段落で、乱暴に聞こえる答え（what）を言ってしまう。前置きの句で「乱暴ですが」と断らず、いきなり言ってよい。あとはその why を、読者の反発を一つずつ外しながら引っぱる。 | 0〜20%（what）、why の核心は後半 | 世間の常識がはっきりしている時評、反論、書き換え、インタビュー回答 |
| **脱線が本題** | 題材に触れたらすぐ、まったく関係のなさそうな話（領域は問わない。[thinking-patterns.md](thinking-patterns.md) の2.から効き方で選ぶ）に入り、それを長めに語る。導入句（「少し離れた話をする」）は付けずに、いきなり話し始める。後で「なぜこんな話をしたかというと」と回収し、脱線そのものが答えだったとわかる。 | 70〜85% | 講演録、題材が小さく扱いやすいもの |
| **二段反転** | 中盤で常識を一度ひっくり返し、読者を納得させる。そのあとで、その反転も実は常識と同じ前提に乗っていたと示し、もう一段深いところに降りる。 | 一度目は40%前後、本当の核は75%以降 | 論争になっている題材、「よく言われる反論」がすでにある題材 |
| **遅延開示** | 卑近な場面から入り、転回と補助線を経て、終盤で初めて核を言葉にする。 | 60〜75% | 上の三つが合わないとき。いちばん無難なので、他が使えるならそちらを優先する。 |

複数の文章を書くときは、型も、入口の種類も、補助線の入り方も、着地も、毎回変える。

## 3. 入口（一つ選ぶ）

- 依頼のされ方から入る（「〜について書けと言われた」）。依頼そのものへの違和感を枕にする。
- 人の一言から入る（学生、取材の記者、店の人）。
- 世間の言い回しから入る（「〜という言葉を最近よく聞く。どうも気持ちが悪い」）。
- いきなり暴論から入る（暴論の先出しの場合）。
- 小さな物や場面の描写から入る。※いちばん使い回されやすい。物から入る場合でも、叙情的な描写にしない。

## 4. 常識の扱い（一つ選ぶ）

- 一文で戯画化して捨てる（「若い者はけしからん、という話である」）。
- 本文の途中で、敵役としてはじめて登場させる。
- 省く（暴論の先出しなら不要なことが多い）。
- 公平に要約して理解を示す。※これを毎回やると「どちらも気持ちはわかる→ただ」という型になる。使うのは三本に一本程度。

## 5. 補助線の使い方

- 補助線は、本題への**当てはめ**で終わらせない。補助線の話の中で一度、予想外の反転を起こす。反転は「妙な話である」「おかしなところがある」と予告せず、事実を置くだけで読者に気づかせる。その反転が、本題を読み替える鍵になる。
- 補助線と本題の対応関係を説明する段落は一つまで。図解のように一対一で対応させると、ただの比喩になる。
- 導入句（「少し離れた話をする」「話が遠回りになるが」）でいちいち断らない。いきなり話し始め、必要なら後で「なぜこんな話をしたかというと」と回収する。

## 6. 射程の伸び縮み

- 入口は手の届く大きさ（一人の学生、一本の映画、一軒の店）。
- どこかで一度、大きく引く（制度、社会、時代、文明）。ときには大風呂敷を広げてよい。「これは日本人が明治以来ずっとやってきたことである」くらいの飛躍は、この文体の味のうちである。ただし一、二文で。
- 「これは〜だけの話ではない」という定型で広げない。

## 7. 概念の導入順

- 鍵になる概念は、まず具体例で現象を見せ、そのあとで名前を与えるか、既存の語を自前で定義し直す。
- 名前は、無難な一般名詞（「協働」「異議」「受容」「見守り」）を教科書的に定義するのではなく、少し大げさな言い方（「時間の主権」「創造的な誤読」「清算されない負債」）を持ち出し、それを卑近な場面に何度も降ろしてみせる。大げさな語と日常語の往復が、この文体の高低差になる。
- 名前を与えたら、以後はその語を道具として使う。

## 8. 着地（一つ選ぶ）

例文は載せない（載せると、そのまま写される）。機能だけを示すので、言葉はその文章の中から探すこと。

| 着地 | 機能 |
|---|---|
| 抽象的な一文で突き放す | それまでの具体を離れ、人間や社会についての一般命題で切る。説明を足さない。 |
| 言い切ってぷつりと終える | 核をもう一度、別の言葉で短く断定して、余韻を残さず終える。 |
| 新しい問いを置いて終える | 本論が開いた次の問いを一つだけ示し、深追いせずに切る。※静かな修辞疑問で余韻を残す終わり方は、書き手が最も選びやすい既定値の一つなので、他を優先する。 |
| 力を抜いて切る | それまでの熱を自分で冷ますような、肩の力の抜けた一言で終える。※肩透かしで流すだけだと、それまでの点数を失う。力を抜いた一言の中に、最後の小さなひねり（核をもう一段ずらす事実や見方）を一つ入れる。 |
| 経緯の報告で閉じる | 依頼や会話から始めた文章で、「そういうことを考えた／話した」と事後報告の形で閉じる。 |
| 時間切れで切る（講演録） | 論の途中で時間に気づいて切り上げる。毎回同じ言い方にしない。 |
| 冒頭の場面に戻る（円環） | 冒頭の細部に触れ直す。ただし本論を通ったことで、その細部の**意味が反転している**ときに限る。同じ小道具をもう一度出して余韻をつくるだけの額縁は使わない。三本に一本程度。 |
| 自嘲で落とす | 書き手自身の小さな失敗や矛盾で落とす。※「〜しようとして、やめた」型は使い回されやすい。 |

どの着地でも避けること：要約（「要するに」「まとめると」「今日お話ししたかったのは」）、教訓・助言（「〜してほしい」）、叙情的な名言、対比文型。そして**処方箋**。終盤で「では、どうすればよいか」に答えて、実務の改善策（「授業で話し合おう」「一言添えよう」）や政策提言（「行政・住民・事業者が役割を分担しよう」）を出すと、とたんに新聞の教育欄か自治体のシンポジウムになる。この文体の終盤が差し出すのは解決策ではなく、問題がなぜこれほど厄介なのかという急所である。

## 9. 書く前のメモ（本文には出さない）

```
ふつうの答え：
ずらした問い：
エンジン（thinking-patterns.md の A〜L から一つ）：
核（一文）：
開示の型：暴論の先出し／脱線が本題／二段反転／遅延開示
入口（3.から一つ）：
常識の扱い（4.から一つ）：
補助線（一本、固有のもの）と、その中で起きる反転：
着地（8.から一つ）：
いちばん最初に思いついた選択（既定値）を一つ捨てたか：
```

最後の項目が大事である。このskillを読んだ書き手が最初に思いつく既定値は、「小さな物や言葉への引っかかりから入り、常識に理解を示し、有名な物語の筋を一段落で紹介して読み替え、70%地点で核を言い、静かな問いか自嘲で終わる」である。少なくとも二か所で、既定値ではないほうを選ぶ。
