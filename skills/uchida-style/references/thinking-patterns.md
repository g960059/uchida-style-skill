# 思考のエンジンと補助線

この文体の議論は「逆張り」ではない。世間の答えを否定するのではなく、**その答えが出てくる問いの枠組みそのもの**を一段外から眺める。だから読者は「言い負かされた」のではなく「そういう見方があったか」と感じる。

## 1. 思考のエンジン（題材に合うものを一篇に一つ）

同じエンジンを毎回使うと、複数の文章を並べたときに「量産品」だとすぐにわかる。題材から自然に出てくるものを選ぶ。

表の「中身」は**問いを立てる角度**であって、結論ではない。中身の文をそのまま結論や決め台詞にすると、同じ題材を書いた文章がみな同じ格言に行き着く（審査で、SNS批判の4本がすべて「言葉は言った本人を縛る」に収束した）。角度だけを借りて、その題材でしか言えない結論を探す。

| エンジン | 中身 | 向いている題材 |
|---|---|---|
| **A. 事後性** | 学びや成熟の意味は、あとになって初めてわかる。事前に値踏みできるものだけを受け取ると、自分が変わる機会を失う。 | 教育、読書、芸術鑑賞、修業。※いちばん使い回されやすい。他のエンジンが使えるなら、そちらを優先する。 |
| **B. 贈与と負債** | 「受け取ってしまった」という負い目が人を動かし、関係と共同体をつくる。等価交換はその場で関係を清算してしまう。損を引き受ける人のところに、ものや人が集まる。 | 商店街、地域、仕事、家族、ボランティア、お礼、贈り物 |
| **C. 集団のパフォーマンス** | 個人の能力の総和ではなく、集団として何ができるか。誰の担当でもない仕事を誰かが引き受けることで、集団の力が最大化する。 | 組織、職場、チーム、学校、行政 |
| **D. 身体と居着き** | 頭で制御しようとすると身体は固まる（居着く）。目的を決めすぎると、その場で起きていることに応じられなくなる。 | 仕事の段取り、効率化、マニュアル、危機対応、スポーツ |
| **E. 消費者マインド** | 最小の対価で最大の商品を得ようとする構えを、教育・医療・政治に持ち込むと、関係そのものが壊れる。買い手は自分を変えようとしない。 | 教育、医療、行政サービス、選挙。※Aと組み合わせて使い回されやすいので、単独で使う。 |
| **F. 他者と応答** | 理解も所有もできない他者からの呼びかけに応答するなかで、「私」は事後的に立ち上がる。「自分らしさ」は先にあるのではない。 | 自分探し、キャリア、恋愛、SNS、承認 |
| **G. 辺境と誤解の創造性** | 中心の規範を遠くから眺め、ずらして受け取るところから、新しいものが生まれる。正確に学ぶことより、誤解のほうが生産的なことがある。 | 日本論、翻訳、外国文化、流行、模倣 |
| **H. 時間のスケール** | 四半期・単年度で測るものと、百年単位で測るもの。制度の値打ちは、それがなかったら起きていたことで測る。 | 公共事業、大学、伝統、農業、地方 |
| **I. 問いの由来を問う** | 「どうすればいいか」ではなく、「なぜ今、これがこんなに問題にされるのか」「誰がこの問いを立てて得をするのか」。 | 時事、炎上、制度改革、流行語 |
| **J. 呪いと祝福** | 人に向けた否定的な言葉（「お前には無理だ」「最近の若者は」）は、言われた側だけでなく言った側も縛る。言葉は記述ではなく、相手を変えてしまう行為である。祝福の言葉は、まだそうなっていない相手を、そうなりうる者として遇する。 | 批判、SNS、子育て、世代論、自己評価 |
| **K. 成熟と幼児化** | 自分の利害だけを基準にする構え（消費者の構え）は、年齢と関係なく人を子どもにとどめる。成熟とは、自分が何を知らないかを知り、他人の分まで引き受けられる範囲が広がることである。 | 権利と義務、クレーム、政治、組織の責任 |
| **L. 数えられないもの** | 帳簿・評価表・数値目標に載らない働きが、実は集団を支えている。※審査で「どの題材も結局ここに着地する」と指摘された。CやBで書けるなら、そちらを使う。「評価する側こそ問題だ」という矛先の反転とセットにしない。 | 最後の手段 |

## 2. 補助線（一本まで。なくてもよい）

補助線は、題材から遠く、しかも**具体的な手触り**があるほど効く。誰でも思いつく匿名の比喩（町歩き、地図、料理、山登り、引っ越し）は効かない。

補助線の**種類**を一つに偏らせない。とくに「有名な物語・映画・昔話の筋を一段落で要約する」型は、使いやすいぶん、どの文章も同じ形になる（審査で12本中8本がこの型になった）。次の系統から、題材に合うものを選ぶ。

| 系統 | 例 | 書き方 |
|---|---|---|
| 言葉の来歴 | 「自由」という訳語、「世間」と「社会」、「お疲れさま」の使われ方 | 語の由来やずれから入る。辞書の引き写しにしない。 |
| 制度・職業の慣行 | 商店のツケ、医師の当直、大工の見習い、町内会の回覧板、入試の採点 | 実際に回っている仕組みの細部を見せる。 |
| 思想家の一つの概念 | モースの贈与と返礼の義務、レヴィ＝ストロースのブリコラージュ、レヴィナスの「他者」 | 名前を出し、一つだけを平易に言い換える。「人類学が教えるように」「よく言われるように」と匿名の権威にしない。 |
| 身体と稽古 | 同じ型を何年も繰り返すこと、「居着く」こと、相手と一つの系をつくること | 稽古場で起きる場面として書く。語り手の経歴として「私は合気道を何十年」とは書かない。 |
| 語り手の身近な経験 | 課題の設定の範囲での教室、職場、家族、近所の出来事 | 課題が与えた立場を超える経歴を足さない。 |
| 作品の一場面 | 『七人の侍』で侍が米の飯で雇われること、『シラノ・ド・ベルジュラック』の代筆 | 筋の要約は二、三文まで。要約に紙幅を取られると、本題との対応がぼやける。 |

補助線を使わずに、題材そのものを掘り下げるだけの文章があってもよい。

補助線は**必ず元の話題に戻ってきて仕事をする**。出して一段落で捨てない。ただし、本題への一対一の**当てはめ**（図解）で終わらせない。補助線の話の中で一度、予想外の反転を起こす（反転を「妙な話である」と予告しない）。その反転が本題を読み替える鍵になると、補助線が議論を生む。

導入句（「少し離れた話をする」「話が遠回りになるが」）は付けず、いきなり話し始めるほうがよい。

自分で引いた補助線に言い訳をしない（「商店と消防署を比べるのは筋違いだが」）。乱暴な補助線は、乱暴なまま押し切るから鮮やかなのである。

仕事の工程や技術（仮縫い、譜めくり）を補助線にするときは、それを個人の心がけやスキル（丁寧な確認、気配り、報連相）の話に縮めない。補助線がよく効くのは、思いどおりにならない他者の身体や時間、清算されないまま残る貸し借り、分業の仕組みが生む空白、といったものに触れているときである。

## 3. 議論の運び方

- **常識の扱いは選ぶ**：一文で戯画化して捨てる、途中で敵役として出す、省く、公平に要約する、のどれか（[disclosure.md](disclosure.md) の4.）。毎回「気持ちはわかる→ただ」と理解を示してから反転すると、それ自体が型になる。
- **言い換えの螺旋**：同じことを三度、少しずつ違う言葉で言い直し、言い直すたびに一歩先へ進む。長い段落の中でやる。
- **定義し直す**：「〜というのは、〜のことである」。辞書の説明ではなく、その文章の中でだけ通用する鋭い定義を与える。
- **小さな具体例 → 大きな一般化 → 小さな具体例に戻る**。
- **自説を仮説として差し出す**：ただし言うべきところは、予告なしにためらいなく言い切る。一方に寄せて押し切り、留保は「たぶん」「と思う」の語尾で済ませる。
- **読者を共犯者にする**：「みなさんにも覚えがあると思う」。
- **最後に見え方を変える**：説教や助言で終えない。着地の仕方は [disclosure.md](disclosure.md) の8.から選ぶ。

## 4. やらないこと

- 賛否両論を並べて「バランスよく」終える。
- 結論を先に言ってから理由を並べる。
- 何の補助線もなく「常識の逆」を言うだけ。
- 補助線を何本も引いて知識を誇示する。
- 「もうひとつ言っておきたいことがある」と別の論点を継ぎ足す。
