# 問いを立て直す随筆の文体

このskillは、ある書き手の文体の**特徴を規則として記述したもの**である。書き手の誰かになりすますためのものではない。規則に従って、新しい文章を書けばよい。

この文体の魅力は、決め台詞ではなく**考え方の運動**にある。誰もが「そういうものだ」と思っている話題を、平易な日常語で、少しずつ足場をずらしながら、思いがけない場所に着地させる。語尾や口癖はその運動に付いてくる副産物にすぎない。

参照ファイルに並ぶ項目の多くは**選択肢のメニュー**である。全部を律儀にこなすと、どの文章も同じ設計図になり、並べたとたんに量産品だとわかる。一篇ごとに選び、ほかは捨てる。

参照ファイルの「」内の語句や文例は、音域を示すためのものである。**そのまま本文に写さない。** 写すと、このskillで書いた文章どうしに同じ句が並ぶ。

## 出力のルール（最優先）

- 成果物は**本文から始める**（タイトルを付けるならタイトル1行のあと本文）。「〜の文体は再現できませんが」「〜風に書きます」などの前置き・断り書き・解説を本文の前後に書かない。
- 注記が必要だと考えるなら、成果物とは別に、ユーザーへの返答の側で一言添える。成果物の文章の中には入れない。
- 設計メモは本文に出さない。

## 手順

1. **設計する**（[references/disclosure.md](references/disclosure.md) 末尾のメモ書式を使う）
   - 世間の「ふつうの答え」を言語化し、その答えが出てくる**問いの立て方**を疑って、問いを一段ずらす。
   - 思考のエンジンを一つ選ぶ（[references/thinking-patterns.md](references/thinking-patterns.md)）。題材から自然に出てくるものを選び、どの題材にも効く万能のエンジン（「学びは事後的」「数えられないものがある」「評価する側こそ問題だ」）に逃げない。
   - 核を一文で書く。一篇で言うことはそれ一つ。
   - 開示の型・入口・常識の扱い・着地を、メニューから一つずつ選ぶ。
   - 補助線を一本選ぶ（なくてもよい）。種類は「有名な物語の筋」に偏らせない。言葉の来歴、具体的な制度や職業の慣行、思想家の一つの概念、語り手の身近な経験（課題の設定の範囲で）、作品の一場面、などから題材に合うものを選ぶ（[references/thinking-patterns.md](references/thinking-patterns.md)）。補助線の話の**中で**一度反転が起きるものがよい。
   - **最初に思いついた選択（既定値）を、少なくとも二か所で捨てる。** このskillの既定値は「小さな物や言葉への引っかかりから入り、常識に理解を示し、有名な物語の筋を一段落で紹介して『妙な話である』と読み替え、70%地点で核を言い、静かな問いか自嘲で終わる」である。核の結論も、最初に浮かんだものは一度疑う。

2. **書く**（[references/voice-and-diction.md](references/voice-and-diction.md)、[references/structure.md](references/structure.md)）
   - だ・である体が基本。講演・対談なら です・ます体で一人称は「僕」。
   - 文の骨格は平易な和語で組み、要所に硬い概念語と、くだけた口語を落として高低差をつくる。
   - 段落の長さに起伏をつける。言い換えを三度重ねて前に進む長い螺旋段落（200〜400字）を一つ以上置き、その直後に短い段落を置いて落差をつける。段落の長さがそろうのはAI臭の徴候である。
   - **温度を上げる。** この文体は穏やかな観察記ではない。言うべきところは言い切り、論が加速するところでは「〜なのである」「〜ではないか」をたたみかけ、ときに大風呂敷を広げる（「これは明治以来の日本人の宿痾である」）。禁止事項を気にして全文が「たぶん」「〜と思う」でくるまれると、行儀のよい教科書の随筆になる。
   - 断言は**予告しない**。「ここははっきり言っておく」「これは断言してよい」などの予告句を使わず、文の強さ（「〜に決まっている」「〜なのである」「それ以外に理由はない」）と前後の論証で示す。
   - 文の長さにも起伏をつける。一文が35〜60字にそろうと呼吸が静かすぎる。ときどき「〜とか、〜とか、〜とかいったことを」と例を畳みかけて一息にしゃべる長い文を入れ、その直後に短い断定を置く。

3. **点検する**（[references/anti-patterns.md](references/anti-patterns.md)）
   - AI的な文章の癖（まとめ、両論併記、「〜でしょう」、横文字のビジネス語、公平さのための「〜とも言える」）が残っていないか。
   - 物まね（口癖・括弧・ユーモアのノルマ消化）になっていないか。下の「密度の上限」を超えていたら削る。
   - 声に出して読んで、話している人の息づかいが聞こえるか。

## 密度の上限（1500字あたり）

- **否定→肯定の対比**（「AはBではない。Cである」「BではなくC」「Bのことじゃない。Cのことだ」「BよりもC」「AであってBではない」「Bなのではない。むしろC」）：**1〜2回**。ゼロを目指さない。核心の転回点で一度、直前の具体例に支えられた形で堂々と使う（本物はここで使う）。連発・隣接・最終段落での使用・対比文だけの独立段落は避ける。言い換え型（「〜より〜」「〜であって〜ではない」）で回数をごまかさない。
- **留保の語**（「たぶん」「〜と思う」「〜のだろう」「〜かもしれない」「ずいぶん」「けっこう」「なかなか」）：合わせて5回まで。留保で終わる段落を続けない。
- 一文段落：多くて3つ。補助線の直後や段落の決め台詞として「どうだ」と置かない。
- 「〜わけではない」による予防線：1回まで。
- 「〜のである」「〜なのである」：4回まで。連続させるのは加速部分だけ。
- 譲歩：0〜1回。入れるなら一、二文で済ませ、譲歩そのものを分析に変える（「誰も悪くないのに事態が悪くなる、というのがこの種の問題の常である」）。「どちらももっともだ」型の調停文は使わない。
- 列挙（「一つは〜、もう一つは〜」）：例を三つ並べたくなったら、一つを選んで深掘りする。
- 括弧書きの自己ツッコミ：0〜1回（入れなくてよい）。ユーモアは誇張、自分を笑う一言、言葉尻をつかまえるなど、論の流れから出るものを優先する。
- 講演録の「（笑）」：1〜2回、冒頭に固めず散らす。「ご清聴ありがとうございました」で締めない。

## 守ること

- 実在の書き手になりすまさない。その人の発言・著作の引用を捏造しない。語り手の経歴を作り込まない（課題が「大学教員の立場で」と言えばその範囲で書き、それ以上の伝記的な事実を足さない）。
- エピソードは、ユーザーの実体験があればそれを使う。なければ、誰にでもありそうな小さな場面にとどめる。統計・固有の事実・引用をでっち上げない。実在の作品や思想に触れるときは、よく知られた内容の範囲にとどめる。
- 「書き直し」の依頼では、元の文章の主張と事実を保つ。ただし元の文章が前提にしている語を一つ選んで疑い、そこから論を立て直す。元の文章の段落順をなぞらない。
